# Slop Valley

A playable, satirical workstation for a solo developer who has become middle management for robots. The game opens directly on three agents and an idea ready for review.

Palette: workstation blue #303acb, ink #20213c, desk #f1f2f8, paper #ffffff, signal green #c6ff7c, attention orange #ff895f. Space Grotesk supplies expressive titles; DM Sans carries controls and prose. Fonts are bundled locally.

The memorable element is a row of colorful agent terminals: each has its own robot icon, personality, live task status and progress. Beneath them the selected idea becomes a substantial workbench, adjacent to a narrow simulated social timeline. The sparse blue sidebar holds upgrades and the founder identity. Cash, audience and attention live in the top utility bar, never a marketing hero.

Desktop: sidebar | agent row, review workbench | timeline. Mobile: compact masthead, scrolling agent selector, review controls then timeline and upgrades. The primary action is always near the idea; keyboard focus, reduced motion and readable labels are required.

Critique: a black-and-neon terminal would make this another coding dashboard. Bright blue chrome and lively agent colors instead evoke a slightly absurd management game; the satire stays in the actual work, output and reactions. Numbers and meters convey game state rather than decorate the page.
